# 갓 노트

굿노트에서 꼭 필요한 기능만 남긴 개인용 필기 앱 (설치형 웹앱, PWA).

- PDF 불러오기 (여러 개 동시, 맥에서는 끌어다 놓기)
- 필기: 펜(필압), 형광펜, 지우개(부분/획 전체), 텍스트, 이미지, 선택·이동
- 형광펜을 긋고 끝에서 잠깐 멈추면 반듯한 직선으로 (거의 가로면 수평으로 맞춤)
- 빈 노트: 무지 / 줄 / 모눈 / 점
- 구글 드라이브 동기화: 내 드라이브의 `갓 노트` 폴더에 저장
- 오프라인에서도 동작하고, 연결되면 자동으로 동기화됩니다.

## 단축키 (맥)
P 펜 · H 형광펜 · E 지우개 · T 텍스트 · V 선택 · ⌘Z 실행 취소 · ⇧⌘Z 다시 실행 · ⌘V 이미지 붙여넣기 · 트랙패드 핀치로 확대

## 1. 인터넷 주소 만들기 (GitHub Pages, 무료)
1. github.com에서 `godnote`라는 **Public** 저장소를 만듭니다.
2. 이 폴더의 파일을 올립니다.
3. 저장소 → Settings → Pages → Branch: `main` / `(root)` → Save
4. 몇 분 뒤 `https://<깃허브아이디>.github.io/godnote/` 에서 열립니다.

## 2. 구글 로그인 준비 (처음 한 번만)
1. https://console.cloud.google.com 에서 새 프로젝트를 만듭니다 (이름 예: 갓노트).
2. **API 및 서비스 → 라이브러리**에서 `Google Drive API`를 찾아 **사용**을 누릅니다.
3. **OAuth 동의 화면**(Google 인증 플랫폼)에서 앱 이름은 `갓 노트`, 대상은 **외부**로 정하고,
   **대상 → 테스트 사용자**에 내 구글 이메일을 추가합니다.
4. **클라이언트 → 클라이언트 만들기** → 유형 **웹 애플리케이션**
   - 승인된 JavaScript 원본: `https://<깃허브아이디>.github.io`, `http://localhost:8765`
   - 승인된 리디렉션 URI: `https://<깃허브아이디>.github.io/godnote/`
5. 만들어진 **클라이언트 ID**(`….apps.googleusercontent.com`)를 `config.js`에 넣고 다시 올립니다.

갓 노트는 `drive.file` 권한만 씁니다. 그래서 갓 노트가 만든 파일만 볼 수 있고, 드라이브의 다른 파일에는 접근하지 못합니다.

## 3. 설치
- **아이패드**: 사파리로 주소 열기 → 공유 버튼 → **홈 화면에 추가**
- **맥**: 사파리로 주소 열기 → 메뉴 **파일 → Dock에 추가**

- **아이패드 (설치 파일로)**: `python3 ipad-launcher/build.py` → `ipad-launcher/build/갓 노트.mobileconfig`를
  에어드롭이나 파일 앱으로 아이패드에 보내 엽니다 → **설정 → 다운로드된 프로파일 → 설치**.
  홈 화면에 갓 노트 아이콘이 생기고, 누르면 주소창 없이 바로 열립니다. 지울 때는 **설정 → 일반 → VPN 및 기기 관리**.

설치한 뒤에는 일반 앱처럼 아이콘을 눌러 실행합니다. 코드를 고쳐서 다시 올리면 앱을 다시 열 때 자동으로 업데이트되므로 재설치할 필요가 없습니다.

## 동기화 동작
- 노트는 기기에 먼저 저장되고, 수정한 지 몇 초 뒤, 앱을 다시 열 때, 1분마다 드라이브와 맞춥니다.
- 같은 노트를 두 기기에서 동시에 고치면 **나중에 저장된 쪽**이 남습니다 (노트 단위).
- 구글 로그인은 1시간마다 만료됩니다. 노트를 열고 닫을 때 자동으로 갱신하며, 이때 로그인 창이 잠깐 떴다가 닫힐 수 있습니다.

## 로컬 실행 (개발용)
```
python3 -m http.server 8765
```
그다음 http://localhost:8765 를 엽니다.
